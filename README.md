A program that writes a single-line code review comment approving a pull request with quiet existential dread — flat, tired-engineer understatement in at most 140 characters. The entry it writes:

> Approved. I read every line twice and found nothing wrong, which mostly means the bug is somewhere I have stopped looking.

## Run it

```sh
python3 main.py
```

Writes the comment to `/output/entry.txt` (pure Python standard library, deterministic).
